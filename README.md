# CivicConnect

CivicConnect is a responsive Drupal 11 web application designed to help community members discover local resources, events, and volunteer opportunities through an accessible and user-friendly interface.

This project demonstrates modern Drupal site building, custom theme development, responsive front-end implementation, and deployment using Pantheon and Git.

---

## Project Overview

CivicConnect connects users with community resources including:

- Community Events
- Local Resource Directory
- Volunteer Opportunities
- Educational Resources
- Food Assistance
- Housing Assistance
- Healthcare Services
- Transportation Services

The application focuses on accessibility, clean design, responsive layouts, and maintainable Drupal development practices.

## Development Workflow

Local development was completed using DDEV.

Typical workflow:

1. Create or update Drupal content
2. Develop custom Twig templates
3. Style components using SCSS
4. Compile assets
5. Test locally
6. Commit changes using Git
7. Push to Pantheon Dev
8. Verify deployment
9. Promote to Test and Live
